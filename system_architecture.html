Request Flow: User Chat Message

1
React Frontend sends POST /chat with message, account_id, session_id + JWT Bearer token
2
JWT Auth Middleware validates token, extracts user_id and role
3
Input Validation checks message length; PII Masking redacts emails, phones, card numbers via Presidio
4
Memory Tools save the user message and retrieve conversation history from PostgreSQL
5
Coordinator Agent sends sanitized message to Groq LLM, which classifies intent → returns ACCOUNT, TRANSACTION, or LOAN
6
Specialized Agent (Account/Transaction/Loan) calls Groq LLM with tool definitions; LLM selects appropriate function calls
7
Tool Functions execute SQL queries against Supabase PostgreSQL via SQLAlchemy, return structured data
8
LLM generates natural language response from tool results; response saved to memory; Audit Log records the action
9
Response returned to React frontend with agent name, response text, and memory message count
